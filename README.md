Um site responsivo desenvolvido com HTML5, CSS3 e Bootstrap 5, inspirado no universo do Aranhaverso. O projeto foi criado com foco em apresentar informações sobre os personagens e filmes de forma acessível e visualmente agradável, sem o uso de JavaScript.

## 📱 Protótipo no Figma
[Protótipo das telas no Figma](https://www.figma.com/design/g8crJdSmpBuMrEJXNXGRPc/SpiderVerce?node-id=41-103&t=M9UE1LBybbtIMwEV-0)

📌 Tecnologias Utilizadas
HTML5

CSS3

Bootstrap 5

🎨 Funcionalidades
📱 Layout responsivo para diferentes tamanhos de tela

📚 Cards com informações dos personagens principais

🎞️ Seção de sinopse dos filmes do Aranhaverso

📸 Galeria de imagens

📧 Formulário de contato fictício

🔝 Botão de "voltar ao topo" feito com ancoragem (sem JS)

Navegação fixa no topo via classes Bootstrap
